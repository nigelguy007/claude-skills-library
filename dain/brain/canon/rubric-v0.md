# Rubric v0 (provisional)

Seed copy of Canon `rubric/current` v0 (`src/agents/b2.ts` `RUBRIC_V0`). Label: **provisional** until the R2 booker interviews (Days 1–10) and the Day 18 calibration pass.

| Criterion | Question the scorer answers | Scale |
|---|---|---|
| Audience fit | Does it name a room an organiser would book for, and that room's problem? | 1–5 |
| Outcome clarity | Could a planner lift one line into a session description as "attendees will leave with…"? | 1–5 |
| Credibility | Is there a confirmed proof point from the Canon, stated no stronger than the claim? | 1–5 |
| Distinctiveness | Would this read the same with another speaker's name on it? | 1–5 |
| Timeliness | Does it connect to a dated signal or current pressure? | 1–5 |
| Voice match | Does it sound like the speaker's samples (phrases, rhythm, register)? | 1–5 |

**Pass:** every criterion ≥ 3 and mean ≥ 3.8 (starting guesses).

**To v1 (Day 12):** a criterion stays only if ≥ 4 of 12 bookers raised it unprompted or ranked it top three. Add Franzoni's four traits (relevant, known by the right people, memorable, easy to work with) to the card sort. "Known" and "easy to work with" describe the speaker, not a post, so if bookers confirm them they belong in the Blueprint and bureau pack, not here.

**Marketing copy:** "built with N event bookers", not "verified buyer demand", until L1 links scores to won bookings.
