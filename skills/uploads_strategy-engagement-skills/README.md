# 5 Claude Skills for the Full Strategy Engagement

Most people use Claude to summarize a deck after the thinking is done. This pack is built
to run more of the actual engagement: framing the real question, sizing the market,
designing the strategic options, planning execution, and tracking whether the value
actually lands.

Five standalone Claude skills, one per stage of a structured strategy engagement. Load
all five for a full engagement, or drop in the one skill you need for the stage you are
stuck at today.

## What's inside

1. **problem-framing-diagnosis** - Turns a vague strategic question into a tested,
   MECE issue tree with a prioritized short list of hypotheses to chase first.
2. **market-competitive-intelligence** - Builds a market sizing view (TAM/SAM/SOM) and
   a structured competitive landscape from fragmented inputs.
3. **strategic-option-design** - Generates a genuinely distinct set of strategic
   options and stress-tests each one against the same evaluation criteria.
4. **operating-model-execution-plan** - Converts a chosen strategy into an operating
   model and a phased execution roadmap with named owners.
5. **value-realization-tracker** - Builds the governance cadence and tracking register
   that shows whether committed value is actually landing after go-live.

## How to install

Two ways to use this pack with Claude:

- **Claude Projects (claude.ai):** create a Project, open Project Knowledge, and upload
  the `SKILL.md` files you want Claude to use. Claude will apply them automatically in
  every conversation inside that project.
- **Claude Code:** drop the skill folders into `~/.claude/skills/` (one folder per
  skill, each containing its `SKILL.md`). Claude Code picks them up automatically.

## Requirements

A Claude subscription (Claude.ai or Claude Code) with the ability to add Project
Knowledge or local skills. No other setup required.

## Example prompt

"Use the problem-framing-diagnosis skill on this situation: our board wants a growth
plan for next year but nobody agrees on the actual problem we're solving. Here's the
context: [paste notes]."
