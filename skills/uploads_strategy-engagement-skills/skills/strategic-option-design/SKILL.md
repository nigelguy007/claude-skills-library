# Strategic Choice and Option Design

## When to use

Use this skill once problem framing and the market fact base are done, and the team
needs to move from "what's happening" to "what should we do." It is built to stop teams
from anchoring on the first idea in the room by forcing genuinely distinct options and a
consistent, honest evaluation of each.

## Instructions

1. Restate the decision the options need to resolve, drawing on the problem statement
   and fact base already established. Confirm the decision scope and the timeframe.
2. Generate 3 to 4 strategic options that are genuinely distinct, not variations on the
   same idea. Push for options that differ on the underlying strategic logic (for
   example: organic build, partnership, acquisition, or exit) not just on execution
   detail.
3. Define a fixed evaluation criteria set before scoring anything (typically: strategic
   fit, expected value creation, execution risk, capital required, and time to impact).
   Use the same criteria for every option.
4. Score each option against every criterion with a one-line justification per score.
   Do not leave any score unexplained.
5. Name the single biggest risk or dependency for each option, and what would have to
   be true for that option to succeed.
6. Recommend one option, or a sequenced combination, with the two or three reasons the
   recommendation follows directly from the scoring, not from a separate judgment call.

## Example prompts

- "Use the strategic-option-design skill to generate distinct growth options for
  entering [market/segment], and score them against fit, value, risk, capital, and
  time to impact."
- "Run this skill on the decision of build vs. partner vs. acquire for [capability],
  given this context and fact base: [paste inputs]."
- "Use strategic-option-design to stress-test these three options the team already
  drafted and flag which one has the weakest evidence behind its top score: [paste
  options]."

## Output

An option evaluation memo: the restated decision, 3 to 4 distinct options with a
one-paragraph description each, a scoring grid against the fixed criteria set with a
justification per score, the single biggest risk per option, and a final recommendation
with the reasoning that ties directly back to the scores.
