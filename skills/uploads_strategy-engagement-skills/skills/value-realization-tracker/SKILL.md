# Governance and Value Realization

## When to use

Use this skill once a strategy is being executed and the organization needs a way to
track whether the value it committed to is actually showing up, not just whether tasks
are getting done. It is built for the recurring governance moment (a monthly steering
committee, a quarterly business review) where leadership needs an honest read on
progress against the original case.

## Instructions

1. Restate the original value case: what outcome was promised, by when, and against
   what baseline. If the baseline is not defined, flag that as a gap before tracking
   anything.
2. Build a value register that lists each committed benefit, its target value, the
   metric used to measure it, current actual value, and status (on track, at risk,
   off track, or realized).
3. Define the governance cadence: how often the register is updated, who owns each line
   item, and who reviews the roll-up.
4. For every line item marked at risk or off track, state the specific reason and the
   corrective action being taken, not a vague "monitoring closely" note.
5. Roll the register up into a single steering-committee view: cumulative value
   realized to date versus the committed case, and the items most at risk of missing
   target.
6. Recommend the 2 to 3 priority actions leadership should take in the next cycle to
   protect the value case.

## Example prompts

- "Use the value-realization-tracker skill to build a governance register for these
  five committed benefits from our transformation program: [paste benefit list]."
- "Run this skill on this list of initiatives and flag which are at risk of missing
  their in-year target, with the reason for each: [paste data]."
- "Use value-realization-tracker to build the steering committee roll-up for this
  quarter, comparing realized value to the original case: [paste inputs]."

## Output

A value realization register (benefit, target, metric, actual, status) plus a
steering-committee roll-up showing cumulative value realized against the committed
case, a reasoned list of at-risk items with corrective actions, and 2 to 3 priority
actions for the next governance cycle.
