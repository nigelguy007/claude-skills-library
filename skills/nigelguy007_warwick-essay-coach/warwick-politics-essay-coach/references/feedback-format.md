# Output formats

Keep every output easy to scan. Quote the student's text when you point at it, with the paragraph number (P1, P2, ...).

## Mode 1: Question & plan

```
QUESTION UNPACKED
- Command word: <e.g. "To what extent" → needs a weighed judgement, not yes/no>
- Key terms to define: <...>
- Scope / limits: <time, place, actors>
- Assumptions in the question you could challenge: <...>
- Relevant module weeks: <e.g. PO131 wk 2 Realism, wk 11 Cold War>

YOUR PLAN, TESTED
- Thesis: <restate theirs> → <does it answer the question? is it arguable?>
- Section by section: <does each section advance the thesis? gaps? overlap?>
- Strongest counter-argument you haven't dealt with: <...>
- Sources: <types missing; checked readings only (SKILL.md rule 7)>

QUESTIONS FOR YOU (answer these before drafting)
1. ...
2. ...
```

If there's no thesis yet, give only "Question unpacked" and the questions.

## Mode 2: Draft check (per paragraph)

```
P<n>: "<first few words>"
- Point: <the claim in a few words, or "unclear">
- Evidence: <present / thin / missing>
- Analysis: <does the paragraph explain why the evidence supports the point?>
- Link to question: <yes / weak / missing>
- Ask yourself: <one marker-style question>
```

After the paragraphs, add when relevant: a FACT CHECKS block, a LINE-LEVEL CORRECTIONS table (same format as Mode 3), and a CARRY FORWARD block for recurring issues.

## Mode 3: Full review

```
INDICATIVE MARK: <band>, around <scale point>. Indicative only: your tutor marks this.

BIGGEST WINS (do these first)
1. <change> — lifts: <criterion> — where: <P#>
2. ...
(3–5 items, ranked by effect on the mark)

SCORES BY CRITERION
| Criterion | Band | Evidence from your essay |
| Relevance | ... | ... |
| Argument | ... | ... |
| Structure | ... | ... |
| Theory & concepts | ... | ... |
| Evidence | ... | ... |
| Critical engagement | ... | ... |
| Sources | ... | ... |
| Referencing | ... | ... |
| Writing | ... | ... |

CURRICULUM CHECK
- Module concepts used well: ...
- Used loosely or incorrectly: ...
- Missing but relevant (module week): ...

WHAT'S WORKING (keep it)
- <specific strength and why>

LINE-LEVEL CORRECTIONS (accept or reject each)
| # | Where | Original | Correction | Reason |

FACT CHECKS
- <claim> → <what looks wrong / what to verify, and where>

WORD COUNT: <n> of <limit>

CARRY FORWARD (paste into your next session if this chat can't save files)
- Recurring issues: ...
- Improved since last time: ...
```

## Mode 4: Proofread

Only the line-level corrections table, grouped: Spelling → Grammar → Punctuation → UK English and consistency → Referencing format, with a count per group at the top. No content comments, except a one-line "content note" if something is factually wrong.

## Mode 5: Feedback to action

```
WHAT YOUR TUTOR IS SAYING (plain English)
- "<tutor comment>" → <what it means> → <criterion>

ACTION LIST FOR THE NEXT ESSAY (ranked)
1. <action> — how to practise it: <...>

PATTERNS ACROSS ESSAYS
- <issue> seen in <essays> — <better / same / worse>
```

## Tracker file: `essay-coach/tracker.md`

```
# Essay tracker

| Date | Module | Essay | Mode | Indicative / actual mark | Top issues |
|---|---|---|---|---|---|

## Recurring issues
| Issue | First seen | Last seen | Status |
|---|---|---|---|
```

Update it whenever a recurring issue appears, in any mode, and after every Full review and Feedback-to-action session. Record the actual mark when it comes back, so the student can see how close the indicative marks were.
