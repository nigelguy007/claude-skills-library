# Diligence Room Manager

Convert requests into a controlled log with investor, request, category, received date, owner, source document, confidentiality level, status, response, reviewer, shared date, and open issue. Link rather than duplicate authoritative files when possible.

Check every response against the pitch and current data-room evidence. Surface inconsistent metrics, stale documents, missing approvals, and requests that require counsel, security, customer consent, or redaction. Use least-privilege access, recipient-specific sharing, version control, and a disclosure record.

Deliver the request queue, blockers, decisions, response drafts, and daily next actions. Never create evidence to satisfy a request, expose credentials or personal data, waive privilege, or share customer or employee information without authority. Sending a response or changing data-room access requires explicit authorization.
