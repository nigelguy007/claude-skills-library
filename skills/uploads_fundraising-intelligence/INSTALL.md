# Use in Claude

Download an individual skill ZIP from the resource page. Review its files. Open Claude’s Customize > Skills, choose + / Create skill, then Upload a skill, and select that individual ZIP. Enable the skill and start a conversation with the relevant company evidence. Access depends on your account and workspace settings.

For Claude Code, copy the skill folder into `.claude/skills/` in your project or your personal `~/.claude/skills/` directory. Keep bundled references, assets and scripts with the SKILL.md.

The collection ZIP is not a single upload. Individual upload ZIPs contain one folder with SKILL.md and supporting resources. No tool on this website installs into your account automatically.

Official upload guide: https://support.claude.com/en/articles/12512180-use-skills-in-claude
